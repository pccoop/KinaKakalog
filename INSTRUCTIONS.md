# Инструкция по запуску проекта «КиноКаталог»

## 1. Системные зависимости

Перед запуском убедитесь, что на компьютере установлены:
- **Node.js** (версия 18.0 или выше) и пакетный менеджер **npm**
- **Python** (версия 3.10 или выше)

---

## 2. Пошаговый запуск

Для работы проекта требуются два запущенных терминала (один для бэкенда, второй для фронтенда).

### Терминал 1: Бэкенд (FastAPI)

```bash
# 1. Перейдите в каталог API
cd api

# 2. Создайте и активируйте виртуальное окружение
# На Linux / macOS:
python3 -m venv .venv
source .venv/bin/activate

# На Windows (PowerShell):
python -m venv .venv
.venv\Scripts\Activate.ps1

# На Windows (Command Prompt):
python -m venv .venv
.venv\Scripts\activate.bat

# 3. Установите зависимости бэкенда
pip install -r requirements.txt

# 4. Запустите сервер API (порт 8000)
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

* API будет доступен по адресу: `http://127.0.0.1:8000`
* Документация Swagger UI: `http://127.0.0.1:8000/docs`
* База данных SQLite создаётся и заполняется начальными данными автоматически.

---

### Терминал 2: Фронтенд (React / Vite)

```bash
# 1. В корневой папке проекта установите npm-зависимости:
npm install

# 2. Запустите сервер разработки (порт 5173):
npm run dev
```

* Интерфейс откроется по адресу: **`http://127.0.0.1:5173`**

---

## 3. Учётные записи для входа

| Роль | Логин | Пароль | Описание доступа |
|---|---|---|---|
| **Администратор** | `admin` | `Admin123!` | Полный доступ: управление фильмами (добавление, редактирование, удаление), журнал действий аудита, панель управления пользователями, личный кабинет |
| **Пользователь** | `user` | `User123!` | Просмотр каталога фильмов, детальные карточки, фильтрация, личный кабинет, смена пароля |

---

## 4. Особенности функционала

1. **Капча-пазл 2х2:** Перед отправкой формы входа или регистрации соберите пазл из 4 фрагментов перетаскиванием мыши (Drag & Drop).
2. **Таймер блокировки:** При 3 неверных вводах пароля или капчи аккаунт блокируется на 60 секунд. На экране отображается живой таймер обратного отсчёта. По истечении таймера вход разблокируется автоматически.
3. **Разблокировка администратором:** Администратор может досрочно разблокировать пользователя в панели управления.
4. **Проверка кода:**
   ```bash
   npm run typecheck  # Проверка строгой типизации TypeScript (0 ошибок)
   npm run build      # Продакшн-сборка бандла
   ```
