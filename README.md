# КиноКаталог (Cinema Catalog)

Модульное веб-приложение для ведения и просмотра каталога фильмов с системой авторизации, интерактивной капчей-пазлом 2х2, таймером временной блокировки, журналом аудита действий и панелью администратора.

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, shadcn/ui, TanStack Query, React Hook Form, Zod
- **Backend:** FastAPI, SQLAlchemy 2.0, Pydantic v2, SQLite (с поддержкой переключения на PostgreSQL/MySQL)

---

## Системные требования

- **Node.js:** версия 18.0 или новее (проверить: `node -v`)
- **npm:** версия 9.0 или новее
- **Python:** версия 3.10 или новее (проверить: `python3 --version`)

---

## Быстрый запуск проекта

Проект состоит из двух частей: сервера API (бэкенд) и клиентского интерфейса (фронтенд). Запустите обе части в отдельных терминалах.

### Шаг 1. Запуск бэкенда (FastAPI)

1. Откройте терминал и перейдите в папку `api`:
   ```bash
   cd api
   ```

2. Создайте и активируйте виртуальное окружение Python:
   - **Linux / macOS:**
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```
   - **Windows (PowerShell):**
     ```powershell
     python -m venv .venv
     .venv\Scripts\Activate.ps1
     ```
   - **Windows (CMD):**
     ```cmd
     python -m venv .venv
     .venv\Scripts\activate.bat
     ```

3. Установите зависимости бэкенда:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите сервер API:
   ```bash
   uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
   ```

- Сервер API будет доступен по адресу: **`http://127.0.0.1:8000`**
- Интерактивная документация Swagger UI: **`http://127.0.0.1:8000/docs`**
- При первом запуске база данных `site_template.db` создаётся автоматически и наполняется стартовой коллекцией фильмов и учётными записями.

---

### Шаг 2. Запуск фронтенда (React / Vite)

1. Откройте второй терминал в корневой папке проекта:
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте браузер по адресу: **`http://127.0.0.1:5173`**

## Тестовые учётные записи

| Роль | Логин | Пароль | Доступные возможности |
|---|---|---|---|
| **Администратор** | `admin` | `Admin123!` | Полный доступ: управление фильмами (создание, редактирование, удаление), журнал аудита действий, управление пользователями и разблокировка, личный кабинет |
| **Пользователь** | `user` | `User123!` | Просмотр каталога фильмов, детальные карточки, фильтрация по жанрам, годам и рейтингам, личный кабинет, смена пароля |

> **Требования к паролям:** минимум 8 символов, обязательно наличие заглавной и строчной буквы, цифры и специального символа (например: `Admin123!`, `User123!`).

## Реализованный функционал

1. **Интерактивная капча 2х2:**
   - Сборка изображения из 4 квадрантов с помощью перетаскивания мышью (Drag & Drop) или кликов.
   - Исходные фрагменты капчи расположены в папке `public/captcha/`.

2. **Защита от перебора паролей и таймер блокировки:**
   - При 3 неверных попытках ввода пароля или неверной сборке капчи учётная запись временно блокируется на **60 секунд** (настраивается в конфигах).
   - На форме входа отображается живой таймер обратного отсчёта (`00:59` → `00:00`), а кнопка «Войти» блокируется.
   - По истечении таймера доступ автоматически возобновляется.
   - Администратор может снять блокировку досрочно через панель управления.

3. **Модуль КиноКаталога:**
   - Витрина фильмов с постерами, цветными бейджами рейтингов, возрастными метками.
   - Поиск по названию и режиссёру, фильтрация по жанрам (чипсы), диапазону годов выпуска, минимальному рейтингу и сортировке.
   - Отдельная страница фильма (`/movies/:id`) с детальным описанием и характеристиками.
   - CRUD-операции для администратора с валидацией через Zod и диалогами подтверждения.

4. **Журнал действий (Activity Log):**
   - Доступен только администраторам.
   - Фиксирует события авторизации, неудачные попытки, блокировки, операции с фильмами и пользователями.
   - Фильтрация по категориям (`auth`, `movie`, `user`), поиск по тексту и пагинация.

5. **Панель администратора (Dashboard):**
   - Управление пользователями: добавление, редактирование данных, смена ролей, снятие блокировок.
   - Защита администратора: невозможно снять с себя права администратора или заблокировать свою учётную запись.

## Настройка и кастомизация шаблона

- **[`src/config/site.config.ts`](file:///src/config/site.config.ts):** Единая точка конфигурации проекта — название сайта, тексты, цветовые палитры, правила паролей, время таймера блокировки (`lockoutDurationSeconds`) и массив активных модулей (`modules`).
- **[`api/app/core/config.py`](file:///api/app/core/config.py):** Серверные настройки — лимиты попыток, время блокировки (`lockout_duration_seconds`), параметры JWT, CORS и сообщения по ТЗ.
